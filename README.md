# Olá! Eu sou um Desenvolvedor de Software 👋

Sou um desenvolvedor focado em criar aplicações robustas, escaláveis e de alta performance. Tenho uma forte base no ecossistema **.NET** e gosto de construir sistemas de ponta a ponta, desde a modelagem do banco de dados e arquitetura de back-end até a interface do usuário. 

Acredito muito em boas práticas de engenharia de software, utilizando padrões como **Clean Architecture** e abordagens como **Vertical Slice** para manter o código organizado e sustentável.

## 🚀 O que estou construindo atualmente

* **Bora:** Desenvolvendo um sistema ERP inovador e competitivo do zero.
* **Projeto OP:** Construindo uma aplicação focada em arquitetura de fatias verticais (Vertical Slice) utilizando **.NET 10** e Clean Architecture, dividida em camadas lógicas para garantir alta coesão.
* **Simulador de Propostas:** Criando uma ferramenta interativa para simulação e geração de propostas de negócios.
